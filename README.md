# KrakenBot — тикеты, новости и опросы для Discord

## Запуск
1. https://discord.com/developers/applications → New Application → Bot → скопировать токен.
2. Пригласить бота по ссылке (подставить ID приложения):
   `https://discord.com/oauth2/authorize?client_id=ID_ПРИЛОЖЕНИЯ&scope=bot+applications.commands&permissions=563310999358608`
   Зачем каждое право — видно на главной странице `/setup` («🤖 Права бота»): бот показывает, чего не хватает и для чего.
3. `pip install -r requirements.txt`
4. Скопировать `.env.example` в `.env` и вписать токен.
5. `python bot.py`

## Настройка сервера (`/setup`)
Когда бота добавляют на сервер, тому, кто его добавил (или владельцу), приходит мастер в ЛС. На сервере тот же мастер — `/setup`.
Если ЛС закрыты, бот пишет в системный канал с просьбой выполнить `/setup`. Изменения применяются кнопкой **«Сохранить и запустить»**.

### 🛡️ Права — кто что может
Каждому праву назначается свой набор ролей (можно несколько). Администраторы и владелец сервера могут всё.

| Право | Что даёт |
|---|---|
| 🎫 Работа с тикетами | видит все тикеты (через «Управлять ветками» в канале тикетов), меняет статус, без перерыва между тикетами |
| 🔔 Уведомления о тикетах | эти роли упоминаются в новом тикете |
| 📢 Опросы | кнопка «Создать опрос» |
| 📰 Новости | кнопка «Опубликовать новость» (Discord + сайт) |
| 🛠️ Ход разработки | сводка для `/progress` |
| 📌 Панель сообщества | публикует панель с кнопками для игроков |
| 🔑 Админка сайта | логин на сайт; роль проверяется при каждом запросе API |
| 📜 Журнал | видит канал журнала |
| ⚙️ Настройка бота | открывает `/setup` (право «Управлять сервером» работает всегда) |
| 👥 Создание тикетов | кто видит канал тикетов и создаёт тикеты; пусто — все |

Кнопка **📋 Эти роли — на все командные права** — быстрый старт: одна роль на всё.
Канал команды видят роли с правами «Опросы», «Новости», «Ход разработки», «Панель сообщества», «Админка сайта».
Свои права участник видит командой `/access`.

### 📁 Каналы
| Канал | Зачем | Права выставляет бот |
|---|---|---|
| 🎫 Тикеты | кнопка «Создать тикет», внутри приватные ветки | да |
| 🛠️ Команда | панель кнопок для команды | да |
| 📰 Новости | сюда идут новости с сайта, подставляется в форму новости | нет |
| 📢 Опросы | подставляется в форму опроса | нет |
| 📜 Журнал | кто создал тикет, сменил статус, опубликовал, получил доступ к сайту, изменил настройки | да |

Права ролей, которые бот сам не выдавал, в этих каналах не меняются. Роль, у которой забрали право в `/setup`, теряет и доступ к каналу.
Каналы ищутся по id — их можно переименовывать.

### 🎫 Тикеты
Категории в форме, перерыв между тикетами (0 с – 1 ч), лимит открытых тикетов на игрока,
когда упоминать команду (всегда / только критичные / никогда), закрывать ли решённые тикеты.

### ✏️ Игра
Название, приветствие панели, текст «Об игре», ссылка на сайт (кнопка «🌐 Сайт игры» в постах и на панели).

## Как работает
- **Создать тикет** → форма: категория, тема, описание, версия/платформа → приватная ветка `#0001 · 🐞 Баг`.
- Кнопки **Взят в работу / Исправлен / Не актуально** — только у «Работа с тикетами».
- **📢 Создать опрос** → пост с кнопкой **💡 Есть идея**: идея приходит тикетом со ссылкой на пост.
  После публикации можно добавить **📊 голосование Discord** (варианты ответа, срок, один или несколько вариантов).
- **📰 Опубликовать новость** → пост в канал и на сайт; последние новости — кнопка «Новости» и `/news`.
- Новости и опросы оформлены карточкой Components V2: цветная полоса, иконка сервера, галерея до 10 картинок/видео одной сеткой,
  дата, кнопки внутри поста. Пост длиннее ~3900 символов уходит обычным эмбедом.
- **📌 Панель сообщества** — Об игре · Новости · Разработка · Идея · Ошибка (+ Сайт игры).

Команды: `/info`, `/news`, `/progress`, `/idea`, `/bug`, `/ticket`, `/access`, `/setup`.

## Docker
Образ собирается GitHub Actions при каждом пуше в `main`: `ghcr.io/luviel19/krakenbot:latest`.
```
docker compose pull && docker compose up -d
```
Данные — в томе `/data` (`data.json`).

## API новостей для сайта
Сайт читает ленту `GET /api/news` и публикует новости через API бота; бот публикует их в Discord.
Новости из Discord сразу попадают в ту же ленту. HTTPS — Caddy в `docker-compose.yml` (Let's Encrypt; порт 80 держит nginx и пересылает
проверки сертификата в Caddy — `deploy/nginx-acme.conf`). Логины админки выдаёт кнопка **🔑 Доступ к сайту**.
Контракт — [API.md](API.md), настройки — `.env.example`.
