# KrakenBot — тикеты для Discord

## Запуск
1. https://discord.com/developers/applications → New Application → Bot → скопировать токен.
2. OAuth2 → URL Generator: отметить только `bot`, ниже в «Разрешениях бота» — Manage Channels,
   Manage Roles, View Channels, Send Messages, Send Messages in Threads, Create Private Threads,
   Manage Threads, Manage Messages, Embed Links, Attach Files, Read Message History, Mention Everyone,
   View Audit Log (чтобы бот знал, кто его добавил, и написал ему мастер настройки).
   Или готовая ссылка: `https://discord.com/oauth2/authorize?client_id=ID_ПРИЛОЖЕНИЯ&scope=bot+applications.commands&permissions=361045945488`
3. `pip install -r requirements.txt`
4. Скопировать `.env.example` в `.env` и вписать токен.
5. `python bot.py`

## Настройка сервера
Когда бота добавляют на новый сервер, тому, кто его добавил (или владельцу сервера), приходит в ЛС мастер:
роль поддержки, канал тикетов, канал команды (выбрать существующий или создать новый), название и описание игры.
После «Сохранить и запустить» бот создаёт каналы, выставляет права и публикует панели.
Изменить настройки — команда `/setup` на сервере (нужно право «Управлять сервером»).
Если ЛС закрыты, бот пишет в системный канал сервера с просьбой выполнить `/setup`.

## Docker
Образ собирается GitHub Actions при каждом пуше в `main` и публикуется в `ghcr.io/luviel19/krakenbot:latest`.

```
echo DISCORD_TOKEN=токен > .env
docker compose up -d
```
Номера тикетов хранятся в томе `/data`.

## Как работает
- **Создать тикет** → форма: категория (выпадающий список), тема, описание, версия/платформа.
- Создаётся приватная ветка `#0001 · 🐞 Баг`, туда добавляется автор, пингуется роль поддержки.
- Видят ветку только автор и роль `898463898582253568` (через право «Управлять ветками» в канале).
- Кнопки **Взят в работу / Исправлен / Не актуально** работают только у этой роли.
  «Исправлен» и «Не актуально» архивируют и блокируют ветку; «Взят в работу» открывает её снова.

## Опросы
Бот создаёт канал `#функционал-бота`, который видит только роль `898463898582253568`.
Кнопка **📢 Создать опрос** → форма: канал, упоминание (@everyone / @here / без), заголовок, текст, референсы (до 10 файлов).
Под опубликованным постом кнопка **💡 Есть идея** — игрок пишет идею, и она приходит тикетом
категории «💬 Идея к опросу» со ссылкой на пост.

## Центр сообщества, новости, ход разработки
В `#функционал-бота` у команды кнопки:
- **📰 Опубликовать новость** — как опрос, но без кнопки «Есть идея». Последние 4 новости игроки видят по кнопке «Новости» и `/news`.
- **🛠️ Ход разработки** — сводка для кнопки «Разработка» и `/progress`.
- **📌 Панель сообщества** — публикует в выбранный канал сообщение с кнопками
  Об игре · Новости · Разработка · Идея · Ошибка. «Идея» и «Ошибка» открывают форму тикета с выбранной категорией.

Команды для игроков: `/info`, `/news`, `/progress`, `/idea`, `/bug`, `/ticket`.
Между тикетами одного игрока — пауза 2 минуты (на роль поддержки не действует).
Название игры и текст «Об игре» — `GAME_NAME` и `GAME_INFO` в начале `bot.py`.

## API новостей для сайта
Сайт читает ленту `GET /api/news` и публикует новости через API бота; бот публикует их в Discord.
Новости из Discord сразу попадают в ту же ленту. HTTPS — Caddy в `docker-compose.yml` (Let's Encrypt,
нужен свободный порт 80). Логины админки сайта выдаёт кнопка **🔑 Доступ к сайту** в `#функционал-бота`.
Контракт — [API.md](API.md), настройки — `.env.example`.

Настройки (роль, имя канала, категории) — в начале `bot.py`. Номера тикетов хранятся в `data.json`.
